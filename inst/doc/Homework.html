3.7

Beta(a,b)的概率密度函数为 \[ f(x;a,b)=\frac{x^{a-1}(1-x)^{b-1}}{B(a,b)}, \quad 0\leq x \leq 1 \] 其中B(a,b)为beta函数。

令\(g(x)=I_{[0,1]}(x)\)，则当\(0<x<1\)且\(a,b>1\)时，有 \[ \frac{f(x;a,b)}{g(x)}\leq \frac{(a-1)^{a-1}(b-1)^{b-1}}{B(a,b)(a+b-2)^{a+b-2}}. \]

当\(0<x<1\)且\(0<a,b\leq 1\)时，有 \[ \frac{f(x;a,b)}{g(x)}\leq \frac{1}{B(a,b)}. \]

具体算法如下

rbeta2 <- function(n, a, b){
  if(a>1 && b>1){
    c <- (a-1)^(a-1)*(b-1)^(b-1)/beta(a,b)/(a+b-2)^(a+b-2)
  } else{
    c <- 1
  }
  y <- runif(n*(c+0.1))
  r <- runif(length(y))
  x <- y[r<dbeta(y,a,b)/c]
  if(length(x)>=n){
    return(x[1:n])
  } else{
    return(c(x, rbeta2(n-length(x), a, b)))
  }
}

cover1 <- function(x,mu0,alpha=0.05){# 判断均值是否落在置信区间内
  n <- length(x)
  return((mu0>mean(x)-qt(1-alpha/2,n-1)*sd(x)/sqrt(n))*
           (mu0<mean(x)+qt(1-alpha/2,n-1)*sd(x)/sqrt(n)))
}
cover2 <- function(x,sigma2,alpha=0.05){# 判断方差是否落在置信区间内
  n <- length(x)
  S <- (n-1) * var(x) / qchisq(alpha, df = n-1)
  return(sigma2<S)
}

set.seed(0)
RandomWalkMCMC <- function(N, sigma2, X1=NULL){
  x <- numeric(N)
  r <- numeric(N)
  sigma <- sqrt(sigma2)
  if(is.null(X1)){
    x[1] <- rnorm(1,0,sigma)
  } else {
    x[1] <- X1
  }
  
  r[1] <- T
  for(i in 2:N){
    y <- rnorm(1, x[i-1], sigma)
    u <- runif(1)
    #a <- exp(abs(x[i-1])-abs(y))
    a <- dnorm(y,0,1)/dnorm(x[i-1],0,1)
    r[i] <- u<a
    x[i] <- r[i]*y + (1-r[i])*x[i-1]
  }
  return(list(x=x, acceptance=r))
}

Answer

由于 \[ P(T=l|T\geq k) =\frac{P(T=l,T\geq k)}{P(T\geq k)} =\frac{p^l(1-p)I(l\geq k)}{1-\sum_{i=0}^{k-1}p^i(1-p)} =p^{l-k}(1-p)I(l\geq k) \]

当\(l\geq k\)时，有\(P(T=l|T\geq k)=P(T=l-k)\)。

因此几何分布具有无记忆性，特别地，\(E[T|T\geq k]=E[T]+k=\frac{p}{1-p}+k\)。

E-step:

\[ \begin{aligned} E_{\lambda_0}[l_c(\lambda)|A] &=n\log{\lambda}-\lambda \sum_{i=1}^n E_{\lambda_0}[X_i|A] \\ &=n\log{\lambda}-\lambda \sum_{i=1}^n \frac{(u_i+\frac{1}{\lambda_0})e^{-\lambda_0u_i}-(v_i+\frac{1}{\lambda_0})e^{-\lambda_0v_i}}{e^{-\lambda_0u_i}-e^{-\lambda_0v_i}} \\ &= n\log{\lambda}-\lambda(\frac{n}{\lambda_0}-l_o^{'}(\lambda_0)) \\ \end{aligned} \]

Q-step:

\(\lambda_{1}=\frac{n}{\frac{n}{\lambda_0}-l_o^{'}(\lambda_0)}\)。

记 \[ f(x)=\frac{n}{\frac{n}{x}-l_o^{'}(x)}=\frac{nx}{n-xl_o^{'}(x)}, \quad x>0. \]

则 \[ f^{'}(x)=\frac{1+\frac{1}{n}x^2l_o^{''}(x)}{(1-\frac{1}{n}xl_o^{'}(x))^2}. \]

因此\(l_o\)为凹函数，有唯一的极大值点。
